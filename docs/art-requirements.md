## 1. 生成方式：逐帧单独出图（最重要）

### 1.1 顺序：0 → 1 → 2 → 3，每张拿上一张当参考图

```
帧0 待机（手放下、嘴闭）
  └─ 以帧0为参考 → 帧1（右手抬到胸腹、嘴闭）
       └─ 以帧1为参考 → 帧2（右手到肩前、嘴微张）
            └─ 以帧2为参考 → 帧3（右手到发言位、嘴张开）
```

每张都做**编辑/图生图**，只改右臂和嘴。这样脸、头发、衣服、光照被参考图锁住，比一次出四格稳定得多。

### 1.2 每张的提示词（中文，可直接用）

**帧0（待机）**

> 角色设定：{蓝发、女仆装、猫耳发饰……}，腰部以上，{正面 / 偏右 45° / 正左侧面 / 135° 回身 / 纯背面}，相机俯角 30°，双手自然放下，嘴闭合。
> 输出：单张 PNG，1024×1024 以上，**纯绿色 #00FF00 背景**（或透明背景），无阴影、无地面、无文字、无边框。角色居中偏下，头顶留约 4% 空白。

**帧1（以帧0为参考图）**

> 编辑这张图：**保持角色、姿势、服装、发型、五官、光照、构图、大小完全不变**，只把她的**右手从放下抬到胸腹之间**（手肘仍贴身，手掌朝前）；嘴保持闭合。背景保持纯绿 #00FF00。其余像素不要动。

**帧2（以帧1为参考图）**

> 继续编辑：把**右手抬到肩前高度**，手掌自然打开；嘴**微张**。头、身体、衣服、发丝、光照、位置完全不变。背景纯绿。

**帧3（以帧2为参考图）**

> 继续编辑：右手抬到**发言位置**（手掌朝前、略高于肩），**嘴张开说话**，表情自然。其余完全不变。背景纯绿。

每张都带上这三句硬约束：
- **只改右臂和嘴，其他完全不变**
- **同一构图、同一大小、同一位置**
- **纯绿背景（或透明），不要阴影/地面/文字**

### 1.3 一致性要求

四张叠一起看，除手臂和嘴以外应几乎重合。允许：头身大小差 ≤ 3%、头顶位置差 ≤ 4 px（1024 画布）。超了就**只重出那一张**，别整组重来。

### 1.4 背景：透明优先，绿幕兜底

- **首选** 透明背景 RGBA。
- 模型给不了透明时：用**纯绿 #00FF00** 或**品红 #FF00FF**，角色边缘不要带绿/品红溢光。我们用色键 + 边缘收缩清掉。
- **不要**浅灰、米色、白色、渐变、环境光——P0 的灰块就是这种底残留。

## 2. 角色规格

| 项 | 要求 |
|---|---|
| 构图 | 腰部以上，底边切在腰/裙腰 |
| 画布 | 1024×1024 或更大，**单帧单图** |
| 朝向 | `12` 正面 / `0130` 45° / `0300` 正侧 / `0430` 135° 回身 / `0600` 背面 |
| 光照 | 统一左上，无强逆光 |
| 边线 | 干净 alpha，无白边/灰边/描边 |
| 文字 | 无文字、水印、边框、网格线 |
| 命名 | `assets/incoming/<模型>/<方位>-<帧号>.png`，如 `deepseek/12-0.png` |

> `0600` 背面看不到手：允许四帧只有身体/头发轻微变化（呼吸感），但**至少一帧要有可辨识的差异**；如果做不到，告诉我，我把背面发言改成身体前后轻晃。

## 6. 我这边怎么拼（你不用管）

1. `assets/_raw/build_single_frames.py` 读单帧 → 去绿幕/清边 → 按头部质心对齐 → 统一缩放到 640×520 画布（头顶 y=40、头中线 x=320）→ 输出 `assets/characters/<模型>/<方位>-<帧号>.png`。
2. 预览页按 80 ms/帧播放 `-0→-1→-2→-3`，保持 2 s，回落两步；对齐后不会跳位。
3. 残余脏边可再跑 rembg / 形态学收缩做二次清理。

## 7. 工具选型：除了 Image2，还有什么能用

| 工具 | 适合做什么 | 成本 | 和我们网页的衔接 |
|---|---|---|---|
| **Live2D Cubism** | **立绘绑定**：一张分层立绘，程序化做呼吸、摇摆、抬手、口型，**永远不会有硬切** | 免费版够用 | 有 Web SDK，可直接进前端 |
| **Rive** | Web 原生交互动画，状态机（待机/发言/倾听），浏览器协作 | 免费档可用 | 导出 `.riv` + JS runtime，直接进前端 |
| **Spine 2D** | 游戏级 2D 骨骼动画，动作最顺 | 付费（约 $99 起） | 有 canvas/webgl runtime |
| **Aseprite / Krita** | 手修帧、补中间帧、清边、对齐 | 便宜/免费 | 导出 PNG 序列，走现有管线 |
| **rembg（开源）** | 自动抠图/清背景 | 免费 | 我们可直接在管线里跑 |
| **Real-ESRGAN / waifu2x** | 放大 + 锐化边缘 | 免费 | 出图分辨率不够时用 |

### 三条路线，你选一条

1. **Live2D（效果最好）**：让 GPT 出**分层立绘**（头、身体、右臂、嘴各一张透明 PNG），我做绑定；抬手/呼吸/摇摆全是程序动画，帧间永不留缝。代价是要分层，素材要求更高。
2. **Rive（网页协作最顺）**：把角色拆成可动部件，做状态机；动画在浏览器实时跑，改动作不用重出图。
3. **继续帧动画（最省事）**：按本文档逐帧单独生成 + 我这边的对齐/清边管线。能到“够用”，但做不到 Live2D 的丝滑。

**我的建议**：P0 先按路线 3 出一版能跑的；如果之后要长期做多模型立绘，转 **Live2D** 或 **Rive** 更划算。

## 8. 常见坑（P0 踩过的）

1. 不要用 2×2 网格——格子背景会残留成灰块，四格缩放还不一致。
2. 不要浅灰/米色/白色底——抠不干净；要么透明，要么亮绿/品红。
3. 不要一次“画四帧”——模型会把四格各自构图，身体对不上。
4. 参考图链按 0→1→2→3 顺序，别跳。
5. 别加阴影/地面——网页里自己打光。
6. 别改脸——帧间脸一变，动起来就是换人。
