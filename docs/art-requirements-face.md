# 圆桌会议 · 角色脸部图层需求（v5 · 整张脸方案）

> 本版只做一件事：把「头部皮肤 + 五官」作为**一张图**出，不再拆眼睛/眉毛/嘴。
> 原因是 Live2D 自动绑定（PSD2Live）会重新排版独立的眼睛层，导致错位；而整脸方案拼装最简单、观感最稳。
> 眨眼和说话用**三张状态图切换**实现。

## 1. 交付物

3 张 PNG，**2048×2048，RGBA，透明背景**，文件名固定：

| 文件 | 内容 | 用途 |
|---|---|---|
| `face-1.png` | 睁眼 + 闭嘴（**主图**，最重要） | 默认状态 |
| `face-2.png` | 睁眼 + 张嘴 | 说话时切换 |
| `face-3.png` | 闭眼 + 闭嘴 | 眨眼时切换 |

每张**只画头部皮肤和五官**：脸、耳朵、腮红、眼睛、眉毛、鼻子（可省略）、嘴。
**不要画**：头发、头饰、衣服、脖子以下、背景、投影。

## 2. 坐标规范（硬要求，误差 ≤ 6 px）

参考图：`assets/incoming/deepseek-p2l/face.png`（当前头部图层，只有皮肤）。
标注图：`preview/face-guide-zoom.png`（绿框=头轮廓，粉框=眼睛，黄框=眉毛，红框=嘴，蓝线=中线/眼线/嘴线）。

| 项目 | 数值 |
|---|---|
| 画布 | 2048 × 2048，透明 |
| 头顶 | y ≈ 323 |
| 下巴 | y ≈ 1450 |
| 脸宽 | ≈ 1188 px（x 429 → 1617） |

| 眉毛中心 | y ≈ 955，宽 ≈ 260，高 ≈ 70 |

头部外轮廓、下巴形状、耳朵位置**必须与参考图一致**；可以重绘，但不要改变大小、位置、朝向。

## 3. 风格

- 日系 Q 版（chibi），脸偏圆、下巴短，眼睛大而亮
- 虹膜蓝色系（与现有蓝紫发色协调），有高光；上眼线深蓝黑，带睫毛
- 细眉，颜色比发色深一档
- 小嘴，闭嘴时带很淡的微笑；张嘴时露一点牙齿/舌头，颜色柔和
- 肤色粉嫩（参考 #FCE6D8，阴影 #F0C9BC），腮红自然
- 光照统一左上，柔和赛璐璐（1–2 层阴影），**不要投影、不要白边、不要发光描边**
- 透明区必须是干净的 alpha，不能有半透明白雾

## 4. 三态一致性（关键）

`face-2`、`face-3` 必须由 `face-1` **编辑**得到，而不是重新画一遍：

- 除眼睛 / 嘴以外，**其余像素完全不变**（脸型、腮红、耳朵、眉毛位置、肤色阴影）
- 闭眼：上眼线变成向下的弧线 + 睫毛，眼白和虹膜不可见
- 张嘴：唇形不变，只增加开口、牙齿和舌头；不要改脸型或下巴
- 三张图的头部轮廓、位置、大小必须能**像素级叠合**

## 5. 生成步骤（建议严格按顺序）

1. 把 `face.png`（或 `face-guide-zoom.png`）作为参考图附上，先生成 **face-1**（睁眼闭嘴）
2. 以 **face-1 为输入图**，指令「只把嘴张开，其他完全不变」→ face-2
3. 以 **face-1 为输入图**，指令「只把眼睛闭上，其他完全不变」→ face-3
4. **一张一张出**，不要拼 2×2 / 1×4 九宫格（会被整体压缩、错位，之前的部件就是这样坏的）
5. 若模型不支持透明背景：用纯绿 `#00FF00` 或纯白背景，但不要渐变、不要阴影，我会抠掉

## 6. 提示词模板（可直接粘贴）

**① 主图（睁眼闭嘴）**

> 参考图是一个 2048×2048 的透明头部图层（只有皮肤，没有头发）。请在同一画布上重绘这个头，保持头部位置、大小、朝向完全一致：头顶 y≈323，下巴 y≈1450，脸宽≈1188，中心 x=1023。补全日系 Q 版五官：大眼睛（眼中心 y≈1165，左右眼中心 x=783 和 1263，单眼约 320×270），蓝色虹膜带高光，深蓝黑上眼线加睫毛，细眉（y≈955），小嘴微笑（中心 1023,1310）。肤色粉嫩，自然腮红，柔和赛璐璐上色，左上光照。不要画头发、头饰、衣服、脖子以下、背景和投影；透明背景，不要白边。输出 2048×2048 PNG。

**② 张嘴**

> 以这张图为底图，保持其它所有像素完全不变，只把嘴改成微微张开：唇形不变，露出少量牙齿和舌头，颜色柔和。不要改眼睛、眉毛、脸型、腮红或轮廓。

**③ 闭眼**

> 以这张图为底图，保持其它所有像素完全不变，只把两只眼睛改成闭眼：上眼线变成向下的弧线并保留睫毛，不显示眼白和虹膜。不要改嘴、眉毛、脸型或轮廓。

## 7. 验收清单

- [ ] 3 张都是 2048×2048 RGBA，透明区干净
- [ ] 头顶 / 下巴 / 脸宽 / 眼睛中心位置误差 ≤ 6 px

- [ ] 没有头发、头饰、衣服、背景、投影
